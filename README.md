# ZAD Management

ERP Backend System built with:

- ASP.NET Core 8
- Clean Architecture
- CQRS
- MediatR
- Entity Framework Core
- SQL Server
- Swagger

## Features

### Companies
- Create
- Update
- Delete (Soft Delete)
- Get All
- Get By Id

### Branches
- Create
- Update
- Delete (Soft Delete)
- Get All
- Get By Id
